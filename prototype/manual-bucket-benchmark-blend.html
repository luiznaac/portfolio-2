Does the Legado bucket move the Benchmark Blend?

The map says a Manual Strategy (Legado) has no Target and no Edition. This demo asks one question: when Legado money sits inside an Asset Class, does the class's benchmark weight change? Model A is today's code: weights come only from the month's Target chain. Model B is the alternative: weights come from the actual allocation, Legado included. Change the numbers and watch the two weights.

What to look at

Model A never moves. The bucket has no Target, so it adds no weight. The denominator is the policy's own Alvo sum. This is the line the glossary draws: “never the actual allocation”.

Model B moves. The bucket's value joins the class's actual value, so the class weight drifts with legacy money. A class with Alvo 0% and only Legado money gets a real weight under B and none under A.

The RF split by sub-class is an approximation in this demo. The real code multiplies the class Alvo by each sub-class Alvo and divides by 100.
