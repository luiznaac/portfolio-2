# Quote APIs for B3 stocks and FIIs — findings and recommendation

Research for [issue #95](https://github.com/luiznaac/portfolio-2/issues/95), 2026-09-14.

**Question:** which market-data source should portfolio-2 use for current prices of B3 stocks and
FIIs (and, if relevant, historical series)? Prices feed the valuation of listed positions and a
monthly rebalancing engine; the backend already pulls CDI/SELIC from the BCB and runs scheduled
jobs via a companion service.

This repo has no prior research-notes directory; findings live in `docs/research/` alongside the
existing `docs/migrations.md`. All "live" evidence below was probed on 2026-09-14 from this
machine (PowerShell `Invoke-WebRequest`), not copied from secondary write-ups.

## TL;DR recommendation

1. **Backbone (valuation + history): B3's own COTAHIST files** — official, free, no auth, no
   quotas, EOD OHLC + volume for every B3-listed asset including FIIs, daily file published after
   close, full history back to 1986. Parse in the existing scheduled job; store one close per
   ticker per trading day. Downside: fixed-width TXT, no intraday, no JSON.
2. **Current-quote API: brapi.dev free plan** — documented REST/JSON, Bearer token, 15,000
   requests/month, 1 ticker per request, ~30 min delay, 3-month history, FII quotes included.
   Enough for a personal portfolio snapshot job and for the SPA to show "today's price" before
   COTAHIST publishes. Pay only if volume, longer history, or dedicated FII endpoints are needed.
3. **Fallbacks:** B3's website quote endpoint (`cotacao.b3.com.br`, undocumented but free and
   already covers FIIs) for best-effort current prices; Yahoo's chart endpoint (deep daily history,
   no auth, but undocumented and terms-ambiguous) for dev/backfill; HG Brasil free (400 req/day)
   as a documented alternative to brapi's free tier.

Do **not** make Yahoo or `cotacao.b3.com.br` the backbone: neither is a documented, stable
contract, and both can change without notice.

## Candidate 1 — B3 public data (COTAHIST files + website quote endpoint)

### 1a. COTAHIST historical series (recommended backbone)

B3 publishes its full historical quote series ("série histórica de cotações") as ZIP-compressed
fixed-width TXT files, linked from the official
[Cotações históricas page](https://www.b3.com.br/pt_br/market-data-e-indices/servicos-de-dados/market-data/historico/mercado-a-vista/cotacoes-historicas/):
the series "traz todo o histórico de preços dos títulos negociados na Bolsa desde 1986" and
includes "nome e código da empresa, código da ação, código ISIN, tipo de mercado … preços
(anterior, abertura, mínimo, médio, máximo, fechamento), quantidade de negócios e volume".

Files verified live (HEAD requests, 2026-09-14):

| File | URL pattern | Size | Last-Modified |
| --- | --- | --- | --- |
| Annual | `https://bvmf.bmfbovespa.com.br/InstDados/SerHist/COTAHIST_A2026.ZIP` | 83,902,668 B | 2026-09-14 23:39 GMT |
| Monthly | `.../COTAHIST_M082026.ZIP` | 10,290,231 B | 2026-08-31 23:47 GMT |
| Daily | `.../COTAHIST_D14092026.ZIP` | 513,815 B | 2026-09-14 23:37 GMT |

- **Current-year annual file is refreshed daily** (last-modified on the probe day, after market
  close). Daily files use `D<DDMMYYYY>`; monthly files use `M<MM><YYYY>`; older annual files
  (`A2023`, `A2025`) are still served. History starts in 1986.
- **Coverage verified by parsing the daily file**: 17,614 records for 2026-09-14, containing both
  stocks and FIIs, e.g. `PETR4` (`010` = mercado à vista, close `48.92`) and `MXRF11`
  (close `9.10`, i.e. `FII MAXI RENCI`). The PETR4 close matches Yahoo's `regularMarketPrice`
  for the same day, a useful cross-check.
- **Auth/limits:** none — plain HTTPS download, no token, no documented quota.
- **Layout:** documented PDF linked from the same page
  (`.../data/files/33/67/B9/50/D84057102C784E47AC094EA8/SeriesHistoricas_Layout.pdf`), plus a demo
  file. Fields are fixed-width; prices are 13-digit integers with 2 implied decimals.
- **Fit for a scheduled job:** ideal for a nightly batch — download the ~0.5 MB daily file (or the
  current-year annual for backfill) after ~21:00 BRT, parse, upsert closes. Observed publication
  time was ~20:37 BRT (23:37 GMT); treat any fixed schedule as "after 21:00 BRT with retry", not
  as a contract. No intraday/real-time data and no JSON; also no dividend adjustments (prices are
  as-traded, "sem nenhum ajuste para a inflação ou proventos").
- **Licensing:** files are published openly by B3 for public consumption; personal use is fine.
  Redistribution/republication would require checking B3's terms — out of scope for a personal
  portfolio app.

### 1b. `cotacao.b3.com.br` website quote endpoint (best-effort current price)

`https://cotacao.b3.com.br/mds/api/v1/instrumentQuotation/{TICKER}` returns the quote shown on
B3's own market-data pages. Verified live, unauthenticated:

- `PETR4` → `curPrc 49.11`, `desc PETROBRAS PN N2`, timestamp `2026-09-14 20:52:20` (BRT);
  `MXRF11` → `9.11`, `FII MAXI RENCI`; `HGLG11` → `148`; `KNRI11` → `156.69`; `VALE3` → `75.7`.
  Response includes open/min/max/avg/last, market name, and status.
- The B3 quotes page
  ([Cotações](https://www.b3.com.br/pt_br/market-data-e-indices/servicos-de-dados/market-data/cotacoes/))
  references `cotacao.b3.com.br` in its own content — it is B3's endpoint, but it is **not part of
  any published B3 API documentation**, has no published rate limits or SLA (no rate-limit headers
  observed; served through Cloudflare), and returns `Cache-Control: no-store`.
- No historical series, no batch multi-symbol call documented. Use as an opportunistic
  current-price fallback with a timeout + cache, never as the sole source.

### 1c. B3 licensed market data

B3's real-time/professional feeds (UMDF etc.) are paid, contract-bound distributor products. They
are overkill for a personal portfolio; not evaluated further.

## Candidate 2 — brapi.dev

Brazilian market-data API, documented REST + OpenAPI, JSON, Bearer token. Facts from the official
[docs](https://brapi.dev/docs), [pricing](https://brapi.dev/pricing),
[FAQ](https://brapi.dev/faq/quais-as-limitacoes) and
[terms](https://brapi.dev/legal/terms-of-use) (all read 2026-09-14):

| Plan | Requests/month | Tickers/request | Quote delay | History | FII basic quotes | Dedicated `/api/v2/fii/*` |
| --- | --- | --- | --- | --- | --- | --- |
| Free (R$ 0, token) | 15,000 | 1 | ~30 min | ≤ 3 months | yes | no |
| Startup (R$ 99.99/mo) | 150,000 | 10 | ~15 min | ≤ 1 year | yes | no |
| Pro (R$ 116.66/mo) | 500,000 | 20 | ~5 min | 10+ years | yes | yes |

- **Coverage:** stocks, BDRs, ETFs, FIIs, funds (FIAGRO/FI-Infra/FIDC/FIP), Tesouro Direto,
  macro (Selic/CDI/IPCA), currencies, crypto, options, futures. FII support has 1,500+ registered
  instruments (logistics, shoppings, lajes, papel, híbridos); dedicated FII endpoints
  (indicators, CVM reports, vacancies, portfolio, dividends) are Pro-only, but **basic FII quotes
  are included in every plan, including Free** (FAQ "Acesso por plano" table).
- **Auth:** `Authorization: Bearer <token>`; sandbox without token covers `PETR4`, `MGLU3`,
  `VALE3`, `ITUB4`, and (per FAQ) `MXRF11`/`HGLG11` on the `/api/v2/fii/*` endpoints. Live check:
  `GET /api/v2/stocks/quote?symbols=PETR4` → 200 without token; `?symbols=MXRF11` and
  `/api/quote/MXRF11` → 401 `MISSING_TOKEN`; `/api/v2/fii/indicators?symbols=MXRF11` → 200 without
  token. So the FII sandbox is limited to the dedicated endpoints — a free **token** is required
  for FII quotes (not independently verified, requires an account).
- **Errors/limits:** rate-limit headers (`RateLimit-Limit/Remaining/Reset`) and 429 +
  `Retry-After`; 401 = missing/invalid token; 403 = feature not in plan.
- **Licensing:** brapi is **not** a B3 licensed distributor/redistributor and says it uses only
  public/open sources (CVM, BCB, public market data). Terms grant a limited, non-exclusive,
  revocable license for use inside your own product (display, cache, derive indicators), but
  prohibit reselling/redistributing the data, building a proxy/mirror/wrapper service, and
  exceeding plan limits. No SLA, no individual contract; data "as is", informational only.
- **Fit for a scheduled job:** good. A daily snapshot of, say, 40 tickers = 40 requests/day
  (~1,200/month) — well inside Free's 15,000. The 1-ticker-per-request limit makes the Free plan
  chatty but irrelevant at personal-portfolio scale; the 30-min delay is fine for valuation, not
  for trading.

## Candidate 3 — Yahoo Finance (undocumented chart endpoint)

There is no official free Yahoo Finance API; the practical endpoint is
`https://query1.finance.yahoo.com/v8/finance/chart/<TICKER>.SA`. Live checks (2026-09-14):

- `PETR4.SA` and `MXRF11.SA` both return 200 with `currency BRL`, `exchangeName SAO`,
  `timezone America/Sao_Paulo`; `instrumentType EQUITY` even for the FII (Yahoo does not classify
  FIIs separately, but prices are present and correct — MXRF11 close matched COTAHIST).
- History: `range=10y&interval=1d` → 2,491 daily points (2016-09-14 → 2026-09-14) for both;
  `range=1y&interval=1d` → 249 points; `range=max` silently degrades to monthly granularity
  (146 monthly points for MXRF11 since 2014). Intraday works: `range=1d&interval=5m` → 85 points.
- **Fragility evidence:** the sibling `v7/finance/quote` endpoint now returns **401** (Yahoo
  requires a cookie/crumb), so only the `chart` endpoint is usable unauthenticated. Yahoo's
  [Developer API Terms](https://legal.yahoo.com/us/en/yahoo/terms/product-atos/apiforydn/index.html)
  apply to Yahoo APIs: revocable, non-sublicenseable license; may not "sell, lease, share,
  transfer, or sublicense" access or "derive income from the use or provision of the Yahoo APIs"
  without written permission; rate limits at Yahoo's sole discretion; no support/continuity
  commitment. For a personal, non-commercial portfolio app this is a gray area, and the
  undocumented endpoint is not covered by any published API contract.
- **Fit:** usable as a dev/backfill fallback (deep daily history, zero setup, delayed prices), but
  not something to build the valuation pipeline on.

## Other candidates checked

- **HG Brasil (HG Finance)** — [docs](https://hgbrasil.com/docs/finance) /
  [pricing](https://hgbrasil.com/pricing): documented JSON API, `key` query param, quotes updated
  every 15–45 min during the session. Free plan: 400 req/day, ações + FIIs + dividends + historical
  data (depth by plan; Pro R$ 49.90/mo = 2 years, Startup R$ 119.90 = 5 years). Valid documented
  alternative to brapi's free tier; free-tier history depth is not stated explicitly.
- **Twelve Data** — [BVMF exchange page](https://twelvedata.com/exchanges/bvmf) lists B3 as EOD
  data requiring **Grow+** (US$29+/mo); the free Basic plan covers only 3 markets + trial symbols
  (trial symbol: PETR4). Rejected on cost for a personal project. (A `stocks?country=Brazil` probe
  with the demo key returned Bovespa symbols, but demo keys are not the free plan.)
- **Alpha Vantage** — the official documentation page has no mention of Bovespa/Brazil/`.SA`;
  no B3 coverage found. Rejected.
- **Scraping Status Invest / Investidor10 / Google Finance** — no public API, terms prohibit
  automated collection. Rejected.

## Recommendation

**Adopt a two-source design, both free:**

1. **B3 COTAHIST daily file as the system of record for prices** (valuation + rebalancing +
   history). A nightly job downloads `COTAHIST_D<DDMMYYYY>.ZIP` after ~21:00 BRT, parses the
   fixed-width records, and upserts `(ticker, date, open, high, low, close, volume)`; a one-off
   backfill can use the current-year annual file (and earlier annuals) without any API quota.
   This is the only source here that is official, free, unlimited, and independent of a vendor.
2. **brapi.dev free plan for current quotes** (SPA "today's price", cross-checks, days when the
   COTAHIST file is late). Create a free token, store it in an env var (backend only, never the
   SPA), cache per ticker per ~30 min, and treat 429/403 as "fall back to last COTAHIST close".

**Fallback chain when the primary current-quote call fails:** brapi → `cotacao.b3.com.br`
(best-effort, undocumented) → last stored COTAHIST close. For history, COTAHIST is already the
primary; Yahoo `chart` is a dev-only cross-check.

**When to pay:** only if the project later needs FII fundamentals (P/VP, DY, CVM reports — brapi
Pro), sub-15-min quotes, or >3-month API history. None of that is required by valuation or a
monthly rebalancing engine, so the free tier plus COTAHIST should be enough indefinitely.

**Integration notes for portfolio-2:** keep the provider behind a gateway port (the repo's
hexagonal layout already separates `gateway/`), so COTAHIST and brapi are two adapters behind one
`QuoteProvider` interface; store fetched prices in the DB so the SPA never depends on a live
third-party call; make the nightly job idempotent and date-keyed.

## Open uncertainties

- brapi free-plan FII quote access is documented but not live-verified (needs an account; the
  unauthenticated FII quote probe returns 401).
- COTAHIST publication time varies; observed ~20:37 BRT, but the job needs retries and a
  "previous close still valid" path. File naming/URLs have been stable for years but are not a
  formal SLA.
- `cotacao.b3.com.br` is undocumented and could be rate-limited or blocked at any time; no B3
  terms page covers it explicitly.
- Yahoo chart endpoint behavior/terms may change (the `v7/quote` 401 is precedent).
- B3 COTAHIST redistribution terms were not reviewed (irrelevant for personal use, relevant if the
  app ever becomes public/multi-user).
